# Al Lahjah Institute: design concept

A static, single-page concept site (English and Arabic, light and dark). No build step.

- `index.html`: the whole page (HTML, CSS and JS in one file)
- `img/`: photographs (CC0 and CC BY stock via Openverse) and the monogram

## Deploy on Vercel

Add New, Project, import this repo, set Framework Preset to **Other**, leave the build command and output directory empty, then Deploy.

## Things to replace before this goes live

- Course names, descriptions and the three steps are illustrative.
- The Arabic text should be reviewed by a native speaker.
- The footer says "Design concept". Remove it only when the institute approves the page.
- Instagram handle and WhatsApp number are set near the top of the script and in the `wa.me` links.
